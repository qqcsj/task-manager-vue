# 有序 · 任务管理

**有序**是一款面向个人学习与日常安排的中文任务管理应用，使用 Vue 3、Vite 和 Tailwind CSS 构建。它将任务清单、状态看板、进度统计和主题设置放在同一个工作空间中，帮助用户记录计划、安排优先级并跟踪完成情况。

项目为纯前端应用，无需注册账号或连接后端，任务保存在当前浏览器中。适合日常任务整理、前端项目学习和课堂实践展示。

## 功能介绍

### 1. 任务管理

支持新建、查看、编辑和删除任务。任务标题必填，描述选填，可以在表单中设置状态和优先级。编辑时回填原内容，删除前显示确认提示，避免误删。卡片保留任务标题、描述、创建日期和快捷操作入口。

### 2. 看板与列表

提供“待办、进行中、完成”三列看板，也可以切换为列表视图。桌面端可拖动卡片到其他列更新任务状态，或直接使用卡片底部的状态下拉框。点击列右上角的加号，可以按该列状态新建任务。

桌面看板三列等宽占满可用区域，手机端纵向排列。两种视图共享同一份任务数据和筛选条件。

### 3. 优先级与卡片装饰

任务分为高、中、低三档优先级，分别使用柔和红色、黄色和绿色卡片，并保留文字标签。每档配有12种小图案，共36种，作为不遮挡文字和按钮的背景装饰。

图案按任务标识稳定分配，刷新或拖动时不会频繁变化；不同任务可能分配到相同图案。深色模式下使用对应的深色配色。

### 4. 搜索与筛选

搜索框支持任务标题、描述、状态和优先级，也支持常见说法与空格分隔的组合搜索，例如：

| 输入示例 | 搜索内容 |
| --- | --- |
| `单词` | 标题或描述中包含“单词”的任务 |
| `中级`、`中优先级` | 中优先级任务，以及其他字段包含该词的任务 |
| `进行中` | 进行中任务，以及其他字段包含该词的任务 |
| `单词 中级` | 同时匹配“单词”和“中级”的任务 |

搜索与状态、优先级下拉筛选共同生效。页面显示当前条件和匹配数量，未匹配的任务只是暂时隐藏，并未删除。点击**“清除筛选，显示全部”**，可以一次清空关键词并恢复全部状态和优先级。

### 5. 任务统计与完成进度

展示全部任务数、进行中数量、完成数量和完成率，并通过进度条与圆环直观呈现。统计始终基于全部任务，不随搜索结果变化。没有任务时完成率为0%。

### 6. 深浅模式与五种主题色

支持浅色、深色模式，以及蓝、红、绿、黄、紫五种主题色。鼠标移入模式控制区域可展开颜色面板；点击颜色只更换主题色，点击模式按钮才切换深浅模式。手机端提供可点击的颜色入口。

模式与主题色分别保存，刷新后保持选择。未手动选择模式时参考系统主题。全局主题色不会改变任务优先级的颜色含义。

### 7. 进度鼓励与首页文案轮换

点击完成率圆环可获得一句鼓励，手机端也有对应入口。系统根据任务情况区分三类内容：全部完成时庆祝，尚未完成时显示剩余数量并鼓励继续，没有任务时引导开始小目标。

内置24句鼓励语，支持“换一句”；同组文案轮换完后再重复。首页另有10组标题与副标题，刷新时成组更换。轮换记录保存在浏览器中，让页面更有变化。

### 8. 本地保存与异常提示

新增、编辑、删除和状态变化后自动保存任务，刷新页面可恢复已保存的数据。存储不可用或写入失败时显示提示；检测到损坏数据时保留原始内容，避免直接覆盖。

## 技术栈

| 技术 | 用途 |
| --- | --- |
| Vue 3 Composition API | 组件、响应式数据与页面交互 |
| Vite | 本地开发服务与生产构建 |
| Tailwind CSS、CSS 变量 | 页面样式、主题和响应式布局 |
| SVG | 界面图标与卡片装饰 |
| localStorage | 任务、主题及文案轮换记录保存 |
| Node.js 内置测试工具 | 输入校验、存储、搜索、主题和文案轮换测试 |
| Python | 提供 PyCharm 启动入口 |

## 本地运行

### 1. 安装依赖

准备 Node.js 22.12或更高版本。下载项目后，在项目根目录执行：

```bash
git clone https://github.com/qqcsj/task-manager-vue.git
cd task-manager-vue
npm install
```

仓库包含 `pnpm-lock.yaml`；已安装 pnpm 时，也可以使用 `pnpm install --frozen-lockfile` 按锁文件安装依赖。选择一种包管理器使用即可。

### 2. 在 PyCharm 中运行

安装依赖后，用 PyCharm 打开 `task-manager-vue` 文件夹，并配置可用的 Python 解释器。

1. 找到项目根目录的 `run_web.py`。
2. 右键该文件，选择运行，创建对应的运行配置。
3. 点击运行窗口中 Vite 输出的 **Local 地址**，即可打开网页。
4. 以后选择该运行配置，点击绿色三角形即可启动。

通常地址为 `http://127.0.0.1:5173/`；端口被占用时会使用其他端口，以控制台输出为准。使用期间保持运行窗口开启，结束后停止运行。

`run_web.py` 负责启动前端开发服务，网页本身仍由 Vue 提供。它不能代替 Node.js 和项目依赖。

### 3. 在终端中运行

```bash
npm run dev
```

打开终端显示的本地地址即可。此项目通过 Vite 运行，不是直接双击 `index.html` 打开的独立静态页面。

### 4. 测试与构建

```bash
npm test          # 运行自动测试
npm run build     # 构建生产文件，输出到 dist
npm run preview   # 构建后在本地预览
```

使用 pnpm 时，对应命令为 `pnpm test`、`pnpm build` 和 `pnpm preview`。测试覆盖任务校验、存储异常、主题设置、搜索组合与文案轮换；具体结果以运行输出为准。

## 数据与使用说明

1. 任务保存在当前浏览器、当前站点的 localStorage 中，不会自动同步到其他设备。
2. 更换浏览器、域名或端口会使用另一份存储；清除本站数据会移除任务与偏好设置。
3. 出现保存失败提示时，当前页面仍可继续操作，但尚未保存的修改可能在刷新后丢失。
4. 上传代码到 GitHub 不等于发布可公开访问的网站。本地开发服务默认只供本机访问。
