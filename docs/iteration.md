# 有序任务管理系统迭代提示词

以下根据本项目的开发过程整理，共 11 轮，可按顺序使用。项目采用 Vue 3、Vite 和 Tailwind CSS，用于课堂实践展示。以下为本项目的提示词。

### 第 1 轮：初始化项目

请使用 Vue 3、Vite 和 Tailwind CSS 创建一个名为“有序”的中文前端任务管理系统，用于课堂实践展示。项目包含 `index.html`、`src/main.js`、`src/App.vue`、基础样式、`package.json` 和 `README.md`，并在 `docs/iteration.md` 中记录迭代过程。先搭建页面骨架，包含应用标题、任务操作区域和任务列表区域，暂不实现完整任务功能。已有仓库直接沿用，没有则初始化 Git。完成后确认可以通过 `npm run dev` 启动并在浏览器访问，运行 `npm run build` 检查构建，以“初始化项目”为主题提交并推送。

### 第 2 轮：实现任务管理功能

请在现有项目中实现任务的新增、查看、编辑和删除。任务包含标题、描述、状态、优先级和创建时间，标题不能为空或全是空格，描述可以不填。状态分为待办、进行中、完成，优先级分为高、中、低，并用红、黄、绿标记。编辑时回填原内容，删除前需要确认。增加标题和描述搜索、状态和优先级筛选，以及任务总数、进行中数量、完成数量和完成率统计。本轮先用内存保存数据，刷新保存留到下一轮。完成后检查增删改查、输入校验和组合筛选，提交并推送。

### 第 3 轮：实现本地数据保存

请使用 localStorage 保存任务，让新增、编辑、删除和状态变化在刷新页面或重新打开同一浏览器地址后仍然保留。首次使用时显示空列表，删除全部任务后也应保持为空。读取和写入失败时给出明确提示，存储内容损坏时不要直接用空列表覆盖原数据，只操作本应用自己的存储内容。保持现有界面和任务功能不变，不增加后端或账号系统。完成后检查各类操作刷新后是否保留，以及异常提示是否正常，提交并推送。

### 第 4 轮：增加看板与拖拽功能

请在现有任务列表基础上增加看板视图，按待办、进行中、完成分成三列，每列显示任务数量，没有任务时显示空状态。支持将任务卡片拖到另一列来修改状态，并自动保存。每列右上角增加新建按钮，打开表单时默认选中该列状态。提供看板和列表的切换入口，两种视图使用同一份任务数据，并保留编辑、删除、搜索、筛选和状态下拉框。完成后实际检查拖拽前后的状态变化、刷新保存和视图切换，提交并推送。

### 第 5 轮：增加深浅模式和手机适配

请为任务管理页面增加浅色模式和深色模式，通过按钮点击切换，并保存用户选择，刷新后保持不变。没有保存记录时可以跟随系统主题。两种模式都要覆盖页面背景、任务卡片、文字、输入框和弹窗，保证文字清楚、优先级容易区分。同时调整手机布局，让看板纵向排列，按钮和表单不超出屏幕。不要改变已有任务数据和操作方式。完成后检查两种模式、刷新记忆以及桌面和手机显示效果，提交并推送。

### 第 6 轮：增加 PyCharm 启动文件

请在项目根目录增加 `run_web.py`，让我能在 PyCharm 中右键运行该文件，之后通过绿色三角形启动网页服务。启动后在运行窗口显示实际访问地址，点击地址即可看到页面。脚本应根据自身位置找到项目，不依赖当前工作目录；缺少 Node.js 或项目依赖时给出清楚的处理提示。只增加启动入口，不修改网页功能或电脑全局配置。完成后检查脚本能否启动服务、输出地址是否可访问，补充简短使用说明，再将启动文件和相关说明提交并推送。

### 第 7 轮：增加五种主题颜色

请在深浅模式基础上增加蓝色、红色、绿色、黄色和紫色五种主题颜色，默认使用紫色。鼠标放到模式按钮区域时显示“选择你喜欢的主题颜色”面板，点击颜色只更换主题色，点击模式按钮才切换深浅模式。按钮、导航和进度等元素随主题色变化，任务优先级仍保持高红、中黄、低绿。五种颜色都要适配深浅模式，刷新后记住选择，并提供手机可点击的颜色入口。完成后检查颜色选择与模式切换互不干扰，提交并推送。

### 第 8 轮：优化整体页面外观

请在不改变现有功能的前提下，把页面整体调整得更清爽、协调。统一侧栏、顶部、统计区域、搜索筛选和任务卡片的间距、圆角与图标风格，减少多余留白，突出任务标题和主要操作。顶部可以加入根据真实任务数据变化的完成进度展示，空状态使用简洁提示。整体保持柔和配色，并兼顾深浅模式、五种主题色和手机显示。完成后检查布局是否整齐、新建编辑删除等操作是否正常，构建通过后提交并推送。

### 第 9 轮：优化任务卡片配色与装饰

请将任务卡片调整得紧凑一些，减少过宽的视觉效果和描述下方的空白，同时保留标题、描述、时间、状态、编辑和删除入口。低优先级整张卡片使用浅绿色，中优先级使用浅黄色，高优先级使用浅红色，深色模式下使用协调的深色版本。每种优先级准备 12 种淡色小图案，例如叶子、花朵、柠檬和小灯，为任务随机分配，刷新后保持原图案。图案放在角落，不遮挡文字或按钮，其他功能不变。完成后检查三档配色、图案稳定性和卡片操作，提交并推送。

### 第 10 轮：让看板三列占满整行

请调整桌面看板的宽度，让待办、进行中、完成三列等宽占满所在行，解决右侧留下大块空白的问题。三列随页面可用宽度自动伸缩，保持适当列间距，并与上方内容区域对齐。保留紧凑的卡片高度、优先级背景和小图案，手机上仍使用单列布局。此次只修改看板布局，不改变其他功能。完成后检查宽屏、普通桌面和手机下是否有多余空白或横向溢出，确认任务操作正常后提交并推送。

### 第 11 轮：完善搜索与恢复全部任务

请完善任务搜索，让搜索框除了标题和描述，还能匹配状态与优先级，输入“中级”或“中优先级”都能找到中优先级任务，也支持“单词 中级”这样的组合搜索。搜索与状态、优先级下拉框共同生效时，要显示当前条件和匹配数量，说明其他任务只是暂时隐藏。在搜索区域增加“清除筛选，显示全部”按钮，一次清空关键词并恢复全部状态和优先级。看板和列表无匹配时给出明确提示，不修改或删除原任务。完成后检查搜索、组合筛选和恢复全部的结果，补充相关测试，提交代码和本轮提示词并推送到 GitHub。
